# Hard++
Not-so-fancy difficulty mod for Minecraft. Set the difficulty to hard. ![image](./src/main/resources/assets/hardplusplus/icon.png)

## Changes
By default, Hard++ does the following...
* 2x health on all mobs
* Passive healing, like from Breath of the Wild master mode
* Undead (specifically Zombies) get a 1.5x speed boost
* Creepers get 1.25x speed
* Fire damage is multiplied by 2
* Explosions are multiplied by 2
* Elytra fireworks are disabled  

Every feature here, however, is fully configurable via the JSON file or, on clients, full [Cloth Config](https://modrinth.com/mod/cloth-config) + [ModMenu](https://modrinth.com/mod/modmenu) support.
